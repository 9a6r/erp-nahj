إصدار تجريبي قابل للتثبيت على Arch Linux وLinux Zen، مبني على ERPNext 16.53.0 وFrappe 16.54.0.

يتضمن تطبيق ديسكتوب GTK/WebKit، العربية والإنجليزية، صورة الخادم الحقيقية، إعداد Podman دون root، والنسخ الاحتياطي والاستعادة. نُشرت الحزمة بعد نجاح اختبار المثبّت على Arch واختبارات المعاملات والاستعادة وإعادة التشغيل باستخدام صورة الخادم المطابقة للبصمة.

التثبيت من المصدر المطابق لهذا الإصدار (Git مطلوب):

```bash
git clone --depth 1 --branch desktop-v0.3.1-rc1 https://github.com/9a6r/erp-nahj.git
cd erp-nahj
./desktop/install.sh --with-server
nahj-desktop
```

من الإعدادات اختر «نظام محلي أو قاعدة بيانات خارجية» لإنشاء موقع؛ تُنزّل صورة الخادم تلقائيًا وتُراجع بصمتها. أو اتصل بخادم مؤسستك عبر HTTPS. يدعم الخادم المحلي x86_64 ويحتاج مساحة للصورة وقاعدة البيانات والنسخ الاحتياطية. أول تشغيل يحتاج الإنترنت لتنزيل الخدمات. يُضاف البرنامج لقائمة التطبيقات.

تتوفر حزمة pacman الجاهزة وصورة الخادم وSHA256SUMS ضمن المرفقات. لتثبيت الحزمة الجاهزة بعد تنزيلها وفحص بصمتها: `sudo pacman -U ./nahj-desktop-0.3.1rc1-1-any.pkg.tar.zst`. للإعداد المحلي من الحزمة، ثبّت `podman podman-compose slirp4netns fuse-overlayfs` وشغّل `sudo python /usr/share/nahj-desktop/setup_rootless.py "$(id -un)"`؛ مثبّت المصدر أعلاه ينفذ ذلك تلقائيًا.

هذا إصدار مرشح للاختبار، وليس ضمانًا شاملًا للاستخدام الإنتاجي. لم تُختبر كل أجهزة الرسوميات أو كل مزودي الخدمات الخارجية. اختبر إعداد شركتك والصلاحيات واستعادة النسخ قبل اعتماد بيانات فعلية. لا تستخدمه لخفض قاعدة ERPNext 17 إلى 16. راجع UPSTREAM-AUDIT.md لتفاصيل الحفاظ على الأصل وحدود التحقق.
